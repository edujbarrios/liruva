# Security Policy

LIRUVA is an early pre-release project and has no production audio features yet.

Please **do not open a public issue with an exploit or secret**. Use GitHub's private vulnerability reporting feature when enabled, or contact the maintainer privately via a contact method published on the repository profile.

We aim to acknowledge good-faith security reports and address them as resources allow. No response-time SLA is offered at this early stage.

Never include API tokens or personal information in bug reports.
